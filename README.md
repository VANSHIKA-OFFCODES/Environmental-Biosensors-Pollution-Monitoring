# Environmental Biosensor Simulation 🌱

A simple Python-Streamlit app that simulates how a biosensor detects pollution levels in the environment. 

## 🔧 Features

- Interactive slider to control sensor sensitivity
- Real-time graph showing pollution fluctuations
- Simulated data for fast visualization

## 🚀 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
